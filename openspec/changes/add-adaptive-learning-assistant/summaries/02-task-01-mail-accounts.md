## 完成内容

- 新增 `MailService`、诊断 Transport 和支持认证的 SMTP Transport。
- 实现规范化邮箱注册、Argon2id 密码哈希、邮箱验证门禁及统一认证失败响应。
- 实现 SHA-256 哈希存储、限时、单次消费的邮箱验证令牌和密码重置令牌。
- 实现并发安全的验证邮件重发与密码重置签发，使用 Serializable 事务和有限 `P2034` 重试。
- 将重发/找回的账户查询、资格判断、令牌签发和邮件发送整体放入受管后台流程，使公开接口统一立即返回 `202`，避免账户枚举时序差异。
- 实现受管后台任务的脱敏错误分类、有界关闭回收、Nest shutdown hooks、SMTP 网络超时和 Compose 停止宽限期。
- 注册保持 `201`；验证、重发和找回端点明确返回 `202`。
- 原始密码和邮件令牌不会进入数据库、Job、响应、日志或快照。
